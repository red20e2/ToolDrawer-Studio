# ToolDrawer Studio 0.1.1

ToolDrawer Studio 0.1.1 is a Windows x64 prerelease focused on making photo calibration practical on real screens.

## Calibration workspace redesign

- Import & Calibrate now uses a large canvas-first image workspace with a narrow right-side control panel.
- Added zoom from 10% through 1600%, including cursor-centered mouse-wheel zoom.
- Added middle-mouse pan and Space + left-drag pan.
- Added Fit Image and 100% view commands.
- Added F11 fullscreen workspace mode.
- Added a collapsible calibration sidebar so the image can use nearly the entire window.
- Added draggable and deletable calibration points with handles that remain a consistent on-screen size while zooming.
- Known Distance calibration now previews the selected point count, pixel distance, entered real-world distance, and calculated px/mm scale before calibration is committed.
- Window size and position are remembered between launches, with invalid/off-screen saved positions safely recentered.

## Compatibility and scope

- Existing photo import, webcam capture, local-network phone capture, pending-capture promotion, and calibration methods are preserved.
- Detect/Edit, Measure, Arrange, Generate, STEP/STL/DXF export, calibration mathematics, project geometry, and manufacturing behavior are unchanged by this release.
- Existing ToolDrawer Studio 0.1.0 release artifacts are not replaced or modified.
- The separate physical manufacturing validation requirement for the V0.1 workflow remains in effect.

## Windows security notice

The V0.1.1 binaries remain unsigned. Windows may therefore display Unknown Publisher or Microsoft Defender SmartScreen warnings even when the files are the official release artifacts.
