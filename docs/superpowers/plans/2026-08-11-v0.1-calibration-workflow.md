# ToolDrawer Studio V0.1 Calibration Workflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the foundation slice's basic two-point calibration into a usable V0.1 calibration workflow with safe image import, A4/Letter and known-object calibration, a printable fiducial target, click-based point capture, confidence gating, and editable project persistence.

**Architecture:** Extend the existing `capture`, `calibration`, controller, and Qt UI modules without changing the canonical millimetre geometry model. OpenCV continues to decode images and solve homographies; a small dependency-free SVG target generator and deterministic contour detector provide printable-target calibration; Qt owns only interaction while controller/services own calibration logic.

**Tech Stack:** Python 3.12, PySide6/Qt, NumPy, OpenCV, pytest, existing `.tds` JSON/ZIP persistence.

## Global Constraints

- Primary platform: Windows desktop.
- Python 3.12-compatible codebase.
- Desktop UI: PySide6 / Qt.
- Image processing: OpenCV.
- Project serialization: Versioned JSON metadata plus embedded binary/image assets in a ZIP-based `.tds` container.
- Internal geometry units remain millimetres regardless of display preference.
- Core features have no network dependency.
- Manual correction/override remains available.
- Project-file schema remains versioned.
- No account, subscription, paid API, project limit, or export paywall may be introduced.
- Photo-derived dimensions must never be presented as metrology-grade measurements.
- Automatic tracing must reject calibration confidence below `0.75` unless the user explicitly opts into a low-confidence override.

```python
from pathlib import Path

import cv2
import numpy as np
import pytest

import tooldrawer_studio.capture.image_loader as loader


def test_load_image_rejects_oversized_file(monkeypatch):
    monkeypatch.setattr(Path, "read_bytes", lambda self: b"x" * (loader.MAX_IMAGE_BYTES + 1))
    with pytest.raises(ValueError, match="too large"):
        loader.load_image(Path("huge.jpg"), "capture-1")


def test_decode_rejects_excessive_pixel_count(monkeypatch, tmp_path):
    pixels = np.zeros((20, 30, 3), dtype=np.uint8)
    ok, encoded = cv2.imencode(".png", pixels)
    assert ok
    path = tmp_path / "image.png"
    path.write_bytes(encoded.tobytes())
    monkeypatch.setattr(loader, "MAX_IMAGE_PIXELS", 500)
    with pytest.raises(ValueError, match="too large"):
        loader.load_image(path, "capture-1")
```

- [ ] **Step 3: Implement shared limits**

```python
MAX_IMAGE_BYTES = 50 * 1024 * 1024
MAX_IMAGE_PIXELS = 40_000_000


def _validate_raw_size(raw: bytes) -> None:
    if len(raw) > MAX_IMAGE_BYTES:
        raise ValueError("Image file is too large; maximum size is 50 MB")


def _validate_pixel_size(pixels: np.ndarray) -> None:

    if width * height > MAX_IMAGE_PIXELS:
        raise ValueError("Decoded image is too large; maximum size is 40 megapixels")
```

- [ ] **Step 3: Implement deterministic target generation/detection**

Generate an SVG whose four black square fiducials are centered at `(inset, inset)`, `(paper.width-inset, inset)`, `(paper.width-inset, paper.height-inset)`, `(inset, paper.height-inset)`. Include thin crosshairs and labelled 100 mm horizontal/vertical verification bars; these are visual aids and not detector inputs.

Detection pipeline:

```python
gray = cv2.cvtColor(image.pixels_bgr, cv2.COLOR_BGR2GRAY)
blurred = cv2.GaussianBlur(gray, (5, 5), 0)
_, mask = cv2.threshold(blurred, 0, 255, cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)
contours, _ = cv2.findContours(mask, cv2.RETR_LIST, cv2.CHAIN_APPROX_SIMPLE)
```

For each contour, require area >= 100 px², approximate with `cv2.approxPolyDP`, require four vertices, convexity, aspect ratio between `0.65` and `1.35`, and fill ratio >= `0.70`. Keep square candidates, select the four whose centers maximize covered quadrilateral area, and order centers TL/TR/BR/BL using sum/difference coordinates. Reject ambiguous sets with confidence below `0.55`.

Target calibration uses the known distance between fiducial centers: `paper.width_mm - 2*inset_mm` by `paper.height_mm - 2*inset_mm`, and stores method `target:{paper.key}`. Final confidence is the minimum of detector confidence and rectangle-transform confidence.

```python
def _store_active_calibration(self, record: CalibrationRecord) -> CalibrationRecord:
    if self._active_capture_id != record.capture_id:
        raise ValueError("Calibration does not belong to the active capture")
    self.project.calibrations = [
        existing for existing in self.project.calibrations
        if existing.capture_id != record.capture_id
    ]
    self.project.calibrations.append(record)
    self._active_calibration = record
    return record
```
