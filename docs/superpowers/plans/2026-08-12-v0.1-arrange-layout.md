# ToolDrawer Studio V0.1 Arrange / Layout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a persistent Arrange stage that lays real calibrated tool cavity footprints into rectangular foam/drawer or Gridfinity boundaries using deterministic, practical-access-first packing plus manual editing controls.

**Architecture:** Add a focused `layout` package for immutable-ish layout contracts, Shapely-backed millimetre geometry, validation/scoring, and deterministic packing. Keep all project mutation and invalidation in `WorkflowController`, persist state through `.tds` schema V3, and keep Qt widgets presentation-only. Generate remains authoritative for final solids; Arrange provides validated 2D placements that later generators consume.

**Tech Stack:** Python 3.12, PySide6/Qt 6, NumPy 2.x, OpenCV 4.x, CadQuery 2.x, Shapely 2.x, pytest 8.x, GitHub Actions Windows Server 2025.

## Global Constraints

- Branch: `feature/v0.1-arrange-layout`, based on `main` commit `8bff69770357369649ee77ff3973e7254b2abe39`.
- Rectangular boundaries only in V0.1.
- Foam/drawer mode uses exact inside width × depth.
- Gridfinity mode uses columns × rows with default pitch 42.0 mm and one continuous usable area; tools may cross nominal cell boundaries.
- Persistent layout coordinates are canonical millimetres with lower-left origin and counter-clockwise degrees.
- Automatic `free` rotation tests 15° increments; `orthogonal` tests 0/90/180/270; `fixed` preserves reference/current orientation.
- Manual free rotation may use arbitrary angles.
- Collision validity uses real contours in millimetres, including existing tool pocket clearance before structural spacing is applied.
- Pocket clearance and structural layout spacing are separate settings.
- Default structural spacing: 3.0 mm.
- Default outer border margin: 4.0 mm.
- Default extra grab-side clearance: 12.0 mm.
- Default manual snap increment: 1.0 mm.
- Required spacing, boundary containment, locked placements, and rotation policies are hard constraints and are never weakened automatically.
- If all tools cannot fit, return the best valid partial arrangement and explicit unplaced tool IDs.
- Locked placements preserve exact position and rotation during repacking.
- Auto/repack is deterministic for identical inputs.
- Qt widgets do not mutate domain objects directly.
- `.tds` migrates V2 -> V3 non-destructively; V1 continues migrating through V2 to V3.
- Opening a project never silently repacks it.
- Unknown future schema versions remain rejected.
- Advanced custom boundaries, persistent groups, multi-view/3D, foam generation, and Gridfinity solid generation are out of scope for this slice.
