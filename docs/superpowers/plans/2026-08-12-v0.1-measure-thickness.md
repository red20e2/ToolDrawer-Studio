# ToolDrawer Studio V0.1 Measure / Thickness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a calibrated side-view Measure stage that estimates maximum physical tool thickness, supports manual correction and exact override, derives safe pocket-depth suggestions, preserves explicit manufacturing overrides, and migrates existing `.tds` projects to schema V2 without changing old pocket geometry.

**Architecture:** Add a focused `measurement` package for measurement types, deterministic OpenCV analysis, and pocket-depth resolution. Keep project mutation, acceptance rules, calibration association, and stale-state invalidation in `WorkflowController`; keep Qt widgets presentation-only. Persist source measurement state in `.tds` V2 through an explicit V1-to-V2 migration, and keep this feature stacked on `feature/v0.1-capture-workflow` until PR #3 is explicitly integrated.

**Tech Stack:** Python 3.12, PySide6/Qt 6, NumPy 2.x, OpenCV 4.x, CadQuery 2.x, pytest 8.x, GitHub Actions Windows runner.

## Global Constraints

- Work on `feature/v0.1-measure-thickness`, based on capture-workflow head `9141e5107b2899d4d2bc48617424acbd50690063`.
- Do not merge, close, or retarget PR #3 during this implementation.
- Python stays `>=3.12,<3.13`; PySide6 `>=6,<7`; NumPy `>=2,<3`; OpenCV `>=4,<5`; CadQuery `>=2,<3`; qrcode `>=8,<9`; pytest `>=8,<9`.
- Internal physical units remain millimetres.
- V0.1 supports one active side-view capture per tool.
- A side-view capture requires its own `CalibrationRecord`; never assume another capture's scale.
- Automatic thickness analysis is deterministic OpenCV/image processing only.
- Automatic acceptance threshold is exactly `0.80`.
- High-confidence automatic results may auto-accept only when no exact manual thickness already has precedence.
- An exact manual thickness remains authoritative when automatic measurement is re-run; re-running may update automatic source data but must not overwrite the manual accepted value.
- Low-confidence automatic output cannot drive pocket-depth suggestion until explicitly accepted, corrected with two endpoints, or replaced by exact manual thickness.
- Manual two-point measurement works even when automatic silhouette detection fails.
- Physical thickness and manufacturing pocket depth are separate values.
- Project defaults are exposed height `4.0 mm` and bottom clearance `0.8 mm`.
- Suggested depth is `accepted_thickness_mm - effective_exposed_height_mm + effective_bottom_clearance_mm`.
- A manual final pocket-depth override is never silently replaced by remeasurement.
- Replacing or recalibrating the side view invalidates image-derived automatic/endpoint state; exact manual thickness and explicit pocket override survive and become review-required.
- Selecting a pending capture uses the existing non-consuming promotion path; the pending item remains in the tray.
- Existing V1 `depth_mm` migrates exactly to V2 `pocket_depth_override_mm`.
- Loading V1 is non-destructive; saving writes V2; future unsupported schema versions are rejected.
- Reopen must restore Measure state without automatically re-running image analysis.
- Gridfinity, foam, 3D reconstruction, multi-view fusion, stepped depth, and AI segmentation remain out of scope.
- The complete existing regression suite must stay green and the final tree must pass Windows CI.

Create `measurement/depth.py`:

```python
from __future__ import annotations

from math import isfinite

from tooldrawer_studio.domain.models import Project, ToolObject


def _nonnegative(value: float, label: str) -> float:
    value = float(value)
    if not isfinite(value) or value < 0:
        raise ValueError(f"{label} must be finite and non-negative")
    return value


def _positive(value: float, label: str) -> float:
    value = float(value)
    if not isfinite(value) or value <= 0:
        raise ValueError(f"{label} must be finite and positive")
    return value


def effective_exposed_height_mm(project: Project, tool: ToolObject) -> float:
    value = project.default_exposed_height_mm if tool.exposed_height_override_mm is None else tool.exposed_height_override_mm
    return _nonnegative(value, "Exposed height")


def effective_bottom_clearance_mm(project: Project, tool: ToolObject) -> float:
    value = project.default_bottom_clearance_mm if tool.bottom_clearance_override_mm is None else tool.bottom_clearance_override_mm
    return _nonnegative(value, "Bottom clearance")


def suggested_pocket_depth_mm(project: Project, tool: ToolObject) -> float | None:
    if not tool.thickness_accepted or tool.accepted_thickness_mm is None:
        return None
    thickness = _positive(tool.accepted_thickness_mm, "Accepted thickness")
    depth = thickness - effective_exposed_height_mm(project, tool) + effective_bottom_clearance_mm(project, tool)
    if not isfinite(depth) or depth <= 0:
        raise ValueError("Measurement settings must produce a positive pocket depth")
    return float(depth)


def final_pocket_depth_mm(project: Project, tool: ToolObject) -> float | None:
    if tool.pocket_depth_override_mm is not None:
        return _positive(tool.pocket_depth_override_mm, "Pocket depth override")
    return suggested_pocket_depth_mm(project, tool)
```

- [ ] **Step 4: Implement sequential migration**

Create `persistence/migrations.py`:

```python
from __future__ import annotations

from copy import deepcopy

CURRENT_SCHEMA_VERSION = 2


def _migrate_v1_to_v2(data: dict) -> dict:
    migrated = deepcopy(data)
    migrated["schema_version"] = 2
    migrated.setdefault("default_exposed_height_mm", 4.0)
    migrated.setdefault("default_bottom_clearance_mm", 0.8)
    for tool in migrated.get("tools", []):
        old_depth = float(tool.pop("depth_mm", 5.0))
        tool.setdefault("side_view_capture_id", None)
        tool.setdefault("automatic_thickness_mm", None)
        tool.setdefault("automatic_thickness_confidence", None)
        tool.setdefault("automatic_thickness_endpoint_a_px", None)
        tool.setdefault("automatic_thickness_endpoint_b_px", None)
        tool.setdefault("corrected_thickness_endpoint_a_px", None)
        tool.setdefault("corrected_thickness_endpoint_b_px", None)
        tool.setdefault("side_view_silhouette_px", [])
        tool.setdefault("accepted_thickness_mm", None)
        tool.setdefault("thickness_measurement_mode", "none")
        tool.setdefault("thickness_accepted", False)
        tool.setdefault("exposed_height_override_mm", None)
        tool.setdefault("bottom_clearance_override_mm", None)
        tool.setdefault("pocket_depth_override_mm", old_depth)
        tool.setdefault("thickness_review_required", False)
    return migrated


def migrate_project_dict(data: dict, from_version: int) -> dict:
    if from_version < 1 or from_version > CURRENT_SCHEMA_VERSION:
        raise ValueError(f"Unsupported project schema version: {from_version}")
    result = deepcopy(data)
    version = from_version
    while version < CURRENT_SCHEMA_VERSION:
        if version == 1:
            result = _migrate_v1_to_v2(result)
            version = 2
            continue
        raise ValueError(f"Unsupported project schema version: {version}")
    result["schema_version"] = CURRENT_SCHEMA_VERSION
    return result
```
