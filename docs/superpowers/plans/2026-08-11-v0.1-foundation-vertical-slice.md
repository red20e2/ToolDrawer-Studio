# ToolDrawer Studio V0.1 Foundation Vertical Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first working ToolDrawer Studio vertical slice that imports a tool photo, calibrates it, finds one or more tool silhouettes, allows non-destructive manual contour correction, saves/reopens an editable `.tds` project, generates one valid parametric pocket, and exports STEP/STL/DXF.

**Architecture:** Use focused Python modules with explicit dataclass-based domain contracts. OpenCV handles deterministic image normalization, calibration, and first-pass silhouette extraction; PySide6 provides a native Windows workflow shell and contour editor; CadQuery generates exact solids and manufacturing exports; a ZIP-based `.tds` archive persists project JSON plus source images. The first slice deliberately proves dimensional flow and persistence before adding webcam/phone capture, advanced packing, foam layering, or local-AI model management.

**Tech Stack:** Python 3.12, PySide6/Qt, NumPy, OpenCV, CadQuery/OpenCascade, SQLite reserved for later library work, pytest, standard-library `zipfile`/`json`/`dataclasses`.

## Global Constraints

- Primary platform: Windows desktop.
- Python 3.12-compatible codebase.
- Desktop UI: PySide6 / Qt.
- Image processing: OpenCV.
- CAD/solid modeling: CadQuery backed by OpenCascade.
- Project serialization: Versioned JSON metadata plus embedded binary/image assets in a ZIP-based `.tds` container.
- Internal geometry units remain millimetres regardless of display preference.
- Core features have no network dependency.
- AI is advisory, not authoritative; this first slice uses deterministic tracing and preserves the interface boundary for later AI tracers.
- Manual correction is always available and must preserve the original source image and base trace.
- Project-file schema is versioned from the beginning.
- CAD generation is deterministic for identical parameters.
- No account, subscription, paid API, project limit, or export paywall may be introduced.
- The initial good-photo dimensional target remains <= 0.5 mm 2D outline error when calibration confidence is high; the UI must not claim metrology-grade accuracy.

```python
# src/tooldrawer_studio/capture/image_loader.py
from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

import cv2
import numpy as np

from tooldrawer_studio.domain.models import CaptureAsset


@dataclass(slots=True)
class LoadedImage:
    asset: CaptureAsset
    pixels_bgr: np.ndarray
    original_bytes: bytes


def load_image(path: Path, capture_id: str) -> LoadedImage:
    raw = path.read_bytes()
    encoded = np.frombuffer(raw, dtype=np.uint8)
    pixels = cv2.imdecode(encoded, cv2.IMREAD_COLOR)
    if pixels is None:
        raise ValueError(f"Unsupported or invalid image: {path}")

    height, width = pixels.shape[:2]
    asset = CaptureAsset(
        id=capture_id,
        filename=path.name,
        width_px=width,
        height_px=height,
        archive_path=f"images/{capture_id}{path.suffix.lower()}",
    )
    return LoadedImage(asset=asset, pixels_bgr=pixels, original_bytes=raw)
```

The loader must reject invalid image bytes with `ValueError`; do not silently create an empty capture.

- [ ] **Step 3: Implement homography-based calibration**

Use a 3x3 homogeneous matrix for both methods so downstream code has one conversion path.

```python
# core shapes for src/tooldrawer_studio/calibration/service.py
from dataclasses import dataclass
from uuid import uuid4

import cv2
import numpy as np

from tooldrawer_studio.domain.models import CalibrationRecord, Point2D


@dataclass(frozen=True, slots=True)
class PixelPoint:
    x_px: float
    y_px: float


def _matrix_tuple(matrix: np.ndarray):
    return tuple(tuple(float(value) for value in row) for row in matrix)


def pixel_to_mm(record: CalibrationRecord, pixel: PixelPoint) -> Point2D:
    matrix = np.asarray(record.matrix_3x3, dtype=np.float64)
    source = np.array([pixel.x_px, pixel.y_px, 1.0], dtype=np.float64)
    mapped = matrix @ source
    if abs(mapped[2]) < 1e-12:
        raise ValueError("Calibration transform maps point to infinity")
    mapped /= mapped[2]
    return Point2D(float(mapped[0]), float(mapped[1]))
```

For known-distance calibration, set `pixel_a` as millimetre origin, rotate the pixel vector from `pixel_a` to `pixel_b` onto the positive X axis, and uniformly scale its length to `known_distance_mm`. This makes the calibration correct even when the ruler line is not horizontal.

For rectangle calibration, call `cv2.getPerspectiveTransform` using corners in top-left, top-right, bottom-right, bottom-left order and destination coordinates `(0,0)`, `(width_mm,0)`, `(width_mm,height_mm)`, `(0,height_mm)`.

Reject zero/negative known distances, identical calibration points, non-positive rectangle dimensions, and degenerate transforms with `ValueError`. Use `method="known_distance"` or `method="rectangle"`; set confidence to `1.0` for exact synthetic tests and reserve richer confidence scoring for the later calibration-quality plan.

- [ ] **Step 3: Implement deterministic silhouette extraction**

Create the contracts in `tracing/models.py`:

```python
from dataclasses import dataclass

from tooldrawer_studio.domain.models import Point2D


@dataclass(frozen=True, slots=True)
class TraceConfig:
    min_area_mm2: float = 100.0
    simplify_mm: float = 0.25


@dataclass(slots=True)
class TraceCandidate:
    base_contour_mm: list[Point2D]
    confidence: float
    area_mm2: float
```

The initial `OpenCVTracer.trace` algorithm is fixed for this task:

1. Convert BGR to grayscale with `cv2.cvtColor(..., cv2.COLOR_BGR2GRAY)`.
2. Apply `cv2.GaussianBlur(gray, (5, 5), 0)`.
3. Produce both Otsu binary polarities with `THRESH_BINARY + THRESH_OTSU` and `THRESH_BINARY_INV + THRESH_OTSU`.
4. Select the polarity whose border pixels are predominantly background (zero) after treating foreground as 255. If both are equivalent, choose the mask with less than 50% foreground coverage.
5. Apply one morphological open and close using a 3x3 elliptical kernel.
6. Call `cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)`.
7. Convert every contour vertex through `pixel_to_mm`.
8. Calculate area in mm² using the shoelace formula on the mapped contour.
9. Reject candidates under `config.min_area_mm2`.
10. Simplify the millimetre contour using a Douglas-Peucker helper with epsilon `config.simplify_mm`.
11. Sort candidates by descending `area_mm2` for deterministic output.

Confidence is a bounded heuristic in `[0,1]`: start at `1.0`, subtract `0.35` if the source contour touches any image border, subtract `0.15` if the contour has fewer than four simplified vertices, and clamp with `max(0.0, min(1.0, score))`.

Use the same real-world X/Y coordinate system as the calibrated tool contour. The base spans `0..base_width_mm`, `0..base_height_mm`, and `0..base_thickness_mm`:

```python
from dataclasses import dataclass

import cadquery as cq

from tooldrawer_studio.domain.models import ToolObject
from tooldrawer_studio.geometry.contour import validate_contour


@dataclass(frozen=True, slots=True)
class PocketSpec:
    base_width_mm: float
    base_height_mm: float
    base_thickness_mm: float
    pocket_depth_mm: float


def tool_profile(tool: ToolObject, apply_clearance: bool = False) -> cq.Workplane:
    validate_contour(tool.contour_mm)
    points = [(p.x_mm, p.y_mm) for p in tool.contour_mm]
    profile = cq.Workplane("XY").polyline(points).close()
    if apply_clearance and tool.clearance_mm > 0:
        profile = profile.offset2D(tool.clearance_mm, kind="arc")
    return profile
```

`build_pocket_insert` must:

1. Reject non-positive base dimensions.
2. Reject `pocket_depth_mm <= 0`.
3. Reject `pocket_depth_mm >= base_thickness_mm` with the message in the test.
4. Build the base with `cq.Workplane("XY").box(width, height, thickness, centered=(False, False, False))`.
5. Create `cavity_profile = tool_profile(tool, apply_clearance=True)`.
6. Inspect the profile bounding box and require at least `0.5` mm material between the cavity and every X/Y base edge.
7. Extrude the cavity by `pocket_depth_mm` and translate it in Z by `base_thickness_mm - pocket_depth_mm`.
8. Return `base.cut(cutter).clean()`.

CadQuery's documented `offset2D()` operation is the required clearance mechanism for this slice; do not raster-expand the contour.

```python
# src/tooldrawer_studio/export/service.py
from dataclasses import dataclass
from pathlib import Path

import cadquery as cq

from tooldrawer_studio.domain.models import ToolObject
from tooldrawer_studio.geometry.pocket import tool_profile


@dataclass(frozen=True, slots=True)
class ExportPaths:
    step: Path
    stl: Path
    dxf: Path


def export_step(model: cq.Workplane, path: Path) -> Path:
    path.parent.mkdir(parents=True, exist_ok=True)
    cq.exporters.export(model, str(path))
    return path


def export_stl(model: cq.Workplane, path: Path) -> Path:
    path.parent.mkdir(parents=True, exist_ok=True)
    cq.exporters.export(model, str(path))
    return path


def export_dxf(tool: ToolObject, path: Path) -> Path:
    path.parent.mkdir(parents=True, exist_ok=True)
    cq.exporters.exportDXF(tool_profile(tool), str(path), doc_units=4)
    return path


def export_tool_package(model: cq.Workplane, tool: ToolObject, directory: Path) -> ExportPaths:
    safe_stem = "".join(ch if ch.isalnum() or ch in "-_" else "_" for ch in tool.name).strip("_") or tool.id
    return ExportPaths(
        step=export_step(model, directory / f"{safe_stem}.step"),
        stl=export_stl(model, directory / f"{safe_stem}.stl"),
        dxf=export_dxf(tool, directory / f"{safe_stem}.dxf"),
    )
```

CadQuery's current documented exporters support STEP/STL from 3D Workplanes and DXF from 2D workplanes; DXF document unit code `4` is millimetres.
