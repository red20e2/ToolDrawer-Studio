# ToolDrawer Studio V0.1.1 Calibration Workspace Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the cramped V0.1.0 Import & Calibrate screen with a canvas-first calibration workspace that gives the image most of the window, supports precise zoom/pan/edit interactions, preserves image-coordinate accuracy, and ships as V0.1.1 without changing downstream manufacturing behavior.

**Architecture:** Keep calibration math, capture services, project schema, tracing, measurement, arrangement, generation, and export logic unchanged. Expand `CalibrationImageView` into a view-state-aware image editor, introduce focused `CalibrationSidebar` and `CalibrationWorkspace` UI components, and keep `MainWindow` as workflow orchestrator. Persist only window geometry in the existing JSON preferences layer; image zoom/pan state remains transient UI state.

**Tech Stack:** Python 3.12, PySide6 6.x, OpenCV 4.x, NumPy 2.x, pytest 8.x, existing PowerShell/Inno Setup release pipeline.

## Global Constraints

- Windows desktop remains the release target.
- Minimum practical window size is approximately 1100 x 700 logical pixels.
- Default window size is approximately 1400 x 900 logical pixels.
- Right sidebar target width is 300-340 logical pixels.
- Image zoom range is 10% through 1600%.
- Newly loaded images open in Fit Image mode.
- Mouse wheel zoom is centered around the pointer.
- Middle-mouse drag and Space + left-drag pan the image.
- Double-click invokes Fit Image.
- 100% means source image pixels at 1:1 image scale.
- Manual zoom/pan survives window resize, maximize/restore, sidebar content changes, and calibration-method changes.
- Calibration point coordinates always remain original full-resolution image coordinates.
- Calibration markers remain approximately constant in on-screen size while zooming.
- Existing calibration methods remain: Known Distance, A4 Sheet, US Letter, Known-size Object, Printable Target.
- Existing capture paths remain: imported photo, webcam, local-network phone capture, pending capture promotion.
- Detect/Edit, Measure, Arrange, Generate, Save/Export, calibration mathematics, manufacturing geometry, and project schema are out of scope for behavioral changes.
- Existing V0.1.0 release artifacts must never be replaced or silently modified.
- New release target is V0.1.1 prerelease.

- Release ends pan.
- Space key release clears `_space_down`.
- Any successful zoom or pan sets `_fit_mode = False`, `_manual_navigation = True`, and emits `fitModeChanged(False)`.
- Double-click calls `fit_image()`.

Do not re-enable permanent scroll bars; the view may keep scroll bars visually hidden while using their values internally for panning.

- [ ] **Step 4: Add live known-distance preview without changing calibration math**

Add to `MainWindow`:

```python
def _update_calibration_preview(self, _points: object | None = None) -> None:
    mode = str(self.calibration_sidebar.calibration_mode.currentData())
    points = self.calibration_view.points_px()
    required = self.calibration_view.required_point_count()
    pixel_distance = None
    scale = None
    if mode == "known_distance" and len(points) == 2:
        pixel_distance = math.hypot(
            points[1].x_px - points[0].x_px,
            points[1].y_px - points[0].y_px,
        )
        known_mm = self.calibration_sidebar.known_distance.value()
        if known_mm > 0:
            scale = pixel_distance / known_mm
    self.calibration_sidebar.set_point_preview(
        len(points), required, pixel_distance, scale
    )
```
