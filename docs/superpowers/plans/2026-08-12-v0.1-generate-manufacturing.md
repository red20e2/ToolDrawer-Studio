# ToolDrawer Studio V0.1 Generate / Manufacturing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the temporary single-tool Pocket Settings/export path with a persistent Generate stage that produces validated foam/drawer or full-featured Gridfinity organizer solids from the exact Measure + Arrange state and exports the complete organizer as STEP, STL, and DXF.

**Architecture:** Add a focused `generation` package. Measure remains authoritative for per-tool pocket depth, Arrange remains authoritative for 2D placement/rotation/grab intent, Generate owns manufacturing settings/validation/body construction/currentness, and Export only writes completed organizer artifacts. Generated CAD stays derived and in-memory; `.tds` V4 persists the recipe and generation metadata, never a serialized BREP/STL.

**Tech Stack:** Python 3.12, PySide6/Qt 6, NumPy 2.x, OpenCV 4.x, CadQuery 2.x/OpenCascade, Shapely 2.x, pytest 8.x, GitHub Actions Windows Server 2025.

## Global Constraints

- Branch: `feature/v0.1-generate-manufacturing`, based on merged `main` commit `21b4071d5273ead9d93412ac93291d844b7366f2`.
- Design spec: `docs/superpowers/specs/2026-08-12-v0.1-generate-manufacturing-design.md`.
- `.tds` advances from schema V3 to V4 with a non-destructive V3 -> V4 migration; V1/V2 projects continue migrating through the existing chain.
- Generated CAD is derived state and is never serialized as project authority.
- Generate never moves tools, changes Arrange rotation, reduces Arrange spacing, weakens manufacturing limits, or alters resolved Measure depth.
- Default height mode: `auto`.
- Default minimum floor: `2.0 mm`.
- Default minimum wall: `2.0 mm`.
- Scoops enabled by default; per-tool required V0.1 modes are `auto` and `off`.
- Gridfinity compatibility baseline is pinned by the design spec to `gridfinity-unofficial/specification` commit `ea7b4f8db05c5060e0cfe683c1e11fe4b3af395d`.
- Gridfinity pitch: `42.0 mm`; nominal top footprint per 1U cell: `41.5 mm`; vertical unit: `7.0 mm`; standard magnet nominal size: `6.0 mm x 2.0 mm`.
- Implement the pinned Gridfinity base profile with centralized constants: profile offsets/heights `(0.0,0.0) -> (0.8,0.8) -> (0.8,2.6) -> (2.95,4.75)`, top corner radius `3.75 mm`, bottom corner radius `0.8 mm`, top cell footprint `41.5 mm`, total base unit height `7.0 mm`.
- Implement the stacking-lip profile with centralized constants: `(0.0,0.0) -> (0.7,0.7) -> (0.7,2.5) -> (2.6,4.4)` before any local omission/fillet treatment.
- Gridfinity magnets are enabled by default at `6.0 mm` diameter and `2.0 mm` depth.
- Gridfinity screw holes are disabled by default; application default M3 clearance diameter is `3.2 mm`.
- Gridfinity stacking lip and 7 mm height snapping are enabled by default.
- Tool cavity geometry must reuse `layout.geometry.oriented_cavity_polygon()` so manufacturing clearance and Arrange transforms cannot drift apart.
- Automatic Gridfinity height may round upward only; manual height is never silently changed.
- Hard manufacturing errors block generation/export; warnings never silently change geometry and do not block export.
- Reopening a project never silently regenerates CAD.
- No new runtime dependency is required for the 3D preview: tessellate the CadQuery solid and render with PySide6/QPainter plus NumPy transforms.
- V0.1 defers laminated/multi-sheet foam, arbitrary polygon drawer boundaries, alternate Gridfinity profile families, randomized/global optimization, and AI/3D capture changes.

    encoded = json.dumps(payload, sort_keys=True, separators=(",", ":"), ensure_ascii=True).encode("utf-8")

- [ ] **Step 4: Implement height resolution**

```python
def resolve_body_height_mm(project: Project) -> float:
    required = required_body_height_mm(project)
    settings = project.generation_settings
    if settings.height_mode == "manual":
        assert settings.manual_height_mm is not None
        if settings.manual_height_mm < required:
            raise ValueError(f"Organizer height must be at least {required:.3f} mm")
        return settings.manual_height_mm
    if project.layout is not None and project.layout.mode == "gridfinity" and settings.gridfinity_height_snap:
        return math.ceil(required / 7.0) * 7.0
    return required
```

`required_body_height_mm()` uses the deepest resolved pocket depth plus floor and later receives Gridfinity feature-floor constraints through validation/builder without ever rounding downward.

def polygon_workplane(polygon: Polygon) -> cq.Workplane:
    exterior = [(float(x), float(y)) for x, y in list(polygon.exterior.coords)[:-1]]
    return cq.Workplane("XY").polyline(exterior).close()


def build_cavity_cutter(tool, placement, depth_mm, body_height_mm):
    polygon = oriented_cavity_polygon(tool, placement)
    return polygon_workplane(polygon).extrude(depth_mm).translate((0.0, 0.0, body_height_mm - depth_mm))

```python
def generate_organizer(project: Project) -> GenerationResult:
    height = resolve_body_height_mm(project)
    validation = validate_generation(project, height)
    if not validation.valid:
        raise GenerationBlockedError(validation.issues)
    body = build_foam_body(project.layout, height) if project.layout.mode == "foam" else build_gridfinity_body(project.layout, height, project.generation_settings)
    for tool, placement, depth in placed_tool_depths(project):
        body = body.cut(build_cavity_cutter(tool, placement, depth, height))
        scoop = build_scoop_cutter(tool, placement, project.layout, project.generation_settings, height, depth)
        if scoop is not None:
            body = body.cut(scoop.cutter)
    body = apply_gridfinity_features_if_needed(body, project, height)
    body = body.clean()
    assert_valid_single_solid(body)
    return GenerationResult(body, generation_fingerprint(project), height, validation_warnings)
```
