# ToolDrawer Studio 0.1.0

ToolDrawer Studio 0.1.0 is the first Windows x64 manufacturing pre-release of the complete local-first workflow.

**Release status:** pre-release pending physical validation. Automated Windows CI, frozen application checks, and deterministic foam/Gridfinity manufacturing fixtures are required gates, but the release is not considered physically validated until the real-world checklist in `docs/V0.1_MANUFACTURING_VALIDATION.md` is completed successfully.

## Included workflow

- Import, webcam, and local-network phone image capture.
- Pixel-to-millimetre calibration using known distances, paper/object references, or printable fiducial targets.
- Editable tool silhouette detection and contour refinement.
- Independent side-view thickness measurement with reviewable/manual correction.
- Deterministic multi-tool Arrange with real cleared contours, spacing, border, grab access, rotations, and locks.
- Explicit manufacturing Generate stage for foam/drawer and parametric Gridfinity organizers.
- Per-tool pocket depths, optional finger scoops, Gridfinity magnets, optional M3 holes, stacking lip, and manufacturing validation.
- Interactive 3D preview.
- Complete-organizer STEP, STL, and DXF export.
- Editable `.tds` schema V4 projects with non-destructive migration from earlier schemas.

## Windows distribution

The tagged release pipeline produces:

- `ToolDrawer-Studio-0.1.0-Setup.exe` - per-user Windows x64 installer.
- `ToolDrawer-Studio-0.1.0-Portable.zip` - portable one-directory application bundle.
- `SHA256SUMS.txt` - SHA-256 checksums for the installer and portable ZIP.

Python is not required on the destination computer. The 0.1.0 binaries are currently unsigned, so Windows may display an unknown-publisher/SmartScreen warning.

## Reliability work included in 0.1.0

- Canonical application version authority.
- Save/Discard/Cancel protection for unsaved projects.
- Recent-project and last-used-folder persistence.
- Local rotating diagnostic logs.
- Honest busy/progress state around CAD generation and export.
- Graceful camera/network-capture degradation so normal import/offline work remains usable.
- Frozen-runtime resource handling and native DLL startup preparation.
- Deterministic release manufacturing self-test.
- PyInstaller Windows packaging plus Inno Setup installer generation.
- PR CI that builds and verifies the real frozen application and uploads release artifacts.

## Known release constraints

- Windows x64 only for 0.1.0.
- No automatic updater.
- No `.tds` Windows file association yet.
- No MSIX package.
- No mandatory Authenticode signing in this pre-release.
- No cloud sync or telemetry.
- Multi-layer foam, automatic printer-bed splitting, custom drawer polygons, and other V0.2 features remain deferred.

## Physical validation

Before promoting this pre-release to production-ready status, complete `docs/V0.1_MANUFACTURING_VALIDATION.md` using a real tool set and a manufactured sample. Record calibration accuracy, known CAD dimensions, STEP/slicer checks, material/process, fit observations, corrections, and final Pass/Fail status.
