# ToolDrawer Studio

ToolDrawer Studio is a pre-release, open-source Windows desktop application for turning calibrated photographs of tools into editable organizer geometry.

The current V0.1 foundation vertical slice focuses on the dimensional core: import a source photo, calibrate pixels to millimetres, trace one or more tool silhouettes, refine contours without destroying the base trace, save/reopen editable `.tds` projects, re-trace stored source images, generate a parametric pocket, and export manufacturing geometry.

## Requirements

- Windows is the primary target platform.
- Python 3.12 is required for development.
- Core design and export features are local-first and do not require an account, subscription, paid API, or internet connection.
